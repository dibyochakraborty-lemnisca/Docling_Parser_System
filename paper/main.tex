\begin{abstract}
Most multi-agent LLM systems for scientific reasoning generate textually plausible explanations directly from raw observations. We argue this paradigm is structurally limited and that the path forward is a world model-inspired architecture: one that compresses noisy observations into stable latent states, articulates falsifiable causal chains, and evaluates consequences against observed reality. We present FASSO (Fermentation Agentic Scientific Synthesis and Observation), a fully open-source, staged architecture for industrial fermentation hypothesis generation that decomposes reasoning into perception, latent-state construction, observational interpretation, and causal hypothesis testing. While FASSO does not execute numerical forward simulations, it performs \emph{semantic state-transition reasoning}—forcing agents to declare downstream consequences of their hypotheses and verifying them against bundle evidence. FASSO introduces a \emph{cumulative cross-run memory} scoped by a closed-vocabulary domain identifier, digesting multi-agent critiques into persistent transition rules so domain priors accumulate across experiments. We detail three structural invariants (schema-enforced provenance, domain-scoped memory, artifact separation) and present a two-part evaluation: an executed cross-vendor architectural audit (composite 9/10) and an empirical process-trace evaluation on a planted-fault dataset. Auditor and judge configurations are in supplementary material.
\end{abstract}

\section{Introduction}
% =========================================================

Industrial fermentation generates exactly the kind of data that breaks single-pass language models. A single penicillin or yeast run produces tens of thousands of timestamped measurements across dissolved oxygen, pH, biomass, substrate, off-gas, temperature, agitation, and feed profiles, accompanied by Excel batch sheets, narrative operator logs in PDF, and process control exports with inconsistent header conventions. When a bioprocess engineer asks why a run lost productivity, the answer requires integrating evidence across these modalities, distinguishing measurement artifacts from biological events, separating observation from inference, and grounding every claim in a specific cell of a specific file. In regulated bioprocess environments, reviewers require explanations whose provenance is strictly traceable to source data.

Contemporary multi-agent scientific reasoning systems—AI Co-Scientist~\citep{aicoscientist}, Robin~\citep{robin}, BioDiscoveryAgent~\citep{biodisco}, SciAgents~\citep{sciagents}—provide LLMs with tools and chain their textual outputs, but fundamentally generate \emph{plausible textual explanations} from observations. They lack stable latent states, temporal consistency, and process-level transition mechanics. A language model guessing ``oxygen limitation'' from a DO drop is pattern matching, not scientific reasoning.

We argue the path forward is a world model-inspired architecture: compressing observations into stable latent states, hypothesizing causal transitions, and evaluating consequences against observed reality. World models in the technical sense map raw observations to a semantic latent state, hypothesize a causal perturbation, and evaluate the downstream evidence implied by that perturbation. FASSO implements this cognitive decomposition (perception, latent-state compression, causal hypothesis, downstream verification) without yet implementing learned dynamics.

We present \textbf{FASSO}, a fully open-source multi-agent architecture organized around cognitive decomposition. It replaces ``LLM + tools + chain-of-thought'' with a pipeline that separates perception (ingestion), latent-state construction (characterization), observational interpretation (diagnosis), and causal reasoning (hypothesis debate). While FASSO does not solve ODEs for biomass growth, it implements \emph{semantic state-transition prediction}: the architecture forces agents to hypothesize causal transitions and empowers a Critic to evaluate whether the expected downstream markers actually materialized in the data.

FASSO features a \emph{compounding cross-run memory}. Unlike standard RAG systems that retrieve text by vector similarity, the FASSO memory layer persists validated critiques and state-transition lessons indexed by a closed-vocabulary \texttt{process\_family} identifier (e.g., \emph{Saccharomyces cerevisiae} aerobic fed-batch). As more runs are analyzed, internal priors accumulate.

The three core structural invariants are:
\begin{itemize}[leftmargin=*, noitemsep]
    \item \textbf{Invariant 1 (Schema-Enforced Citation).} Every hypothesis claim carries a non-empty list of citations to upstream findings, enforced at schema validation before any downstream agent reads the claim. This addresses the failure mode PiFlow~\citep{piflow} identifies—claims lacking links to supporting evidence—by making unlinked claims structurally invalid at object construction time rather than discouraged via prompts.
    \item \textbf{Invariant 2 (Domain-Scoped Memory).} Cross-run lessons are keyed on a closed-vocabulary \texttt{process\_family} validated at the protocol boundary. Queries without a domain key raise an exception. This addresses Rupprecht's~\citep{rupprecht2026} observation that only one of nine surveyed chem-eng MAS uses a fixed domain ontology, extending the design from knowledge representation into memory routing and making cross-domain contamination structurally impossible.
    \item \textbf{Invariant 3 (Observational--Causal Artifact Separation).} Observational reasoning (what happened) and causal reasoning (why) are separated at the typed JSON artifact boundary between stages, not within a single agent's prompt. This prevents causal speculation contaminating evidence summaries—a failure mode no surveyed system structurally prevents.
\end{itemize}

We position the architecture against chem-eng MAS in Section~\ref{sec:related}, detail mechanics in Section~\ref{sec:system}, and present the two-phase evaluation in Section~\ref{sec:evaluation}.

\section{Related work}
\label{sec:related}
% =========================================================

\paragraph{Multi-agent scientific reasoning and world-model inspiration.} 
AI Co-Scientist~\citep{aicoscientist} established the contemporary template for multi-agent hypothesis generation through Elo-based tournament refinement. PiFlow~\citep{piflow} diagnoses the core failure mode of this family: hypotheses ``lack clear direction, leading to uncertainty in establishing clear links between hypotheses and their supporting or refuting evidence.'' The world-models literature~\citep{lecun2022,ha2018,hafner2023} emphasizes reasoning through learned state evolution rather than reactive generation. FASSO draws inspiration from this paradigm without claiming implementation parity—by compressing observations into a stable latent space and forcing agents to articulate downstream consequences, it transforms multi-agent debate from a textual plausibility contest into evidence-against-reality evaluation.

\paragraph{Multi-agent systems in chemical engineering.} 
The Rupprecht review~\citep{rupprecht2026} surveys nine systems and identifies six open challenges: tailored architectures, tool integration, structured databases, domain-ontology-backed knowledge representation, human integration, and domain-specific foundation models. Pajak et al.~\citep{pajak} use multi-objective debate for sustainable operations; Zeng et al.~\citep{zeng} apply multi-agent collaboration to process optimization. Only one of the nine surveyed systems uses a fixed domain ontology. Our closed-vocabulary \texttt{process\_family} enum addresses this directly, extending ontology from knowledge representation into \emph{routing} and \emph{memory scoping}. FASSO addresses five of the six challenges: directed-cyclic-graph hypothesis stage within a staged pipeline (architecture), bounded tool surfaces with structured contracts (tools), typed artifacts plus managed memory (databases), the closed-vocabulary enum (ontology), and HITL pause/resume with state preservation (human integration). Domain-specific foundation models remain future work. To our knowledge, no surveyed system addresses more than two challenges simultaneously.

Table~\ref{tab:comparison} compares FASSO against representative AI-for-science and chem-eng MAS systems. FASSO is the only system combining schema-enforced citation, closed-vocabulary scoping, cross-run memory, and source-data provenance. It does not implement learned forward dynamics—the JEPA gap acknowledged in Section~\ref{sec:discussion}.

\paragraph{Cross-run memory and debate.} 
Multi-agent debate improves factual accuracy over single-agent baselines~\citep{du2023,liang2023}. However, self-critique by the same underlying model is unreliable~\citep{huang2024}, a symptom of broader structural failures in multi-agent systems~\citep{cemri2025}. We address this through asymmetric information design plus a persistent memory layer: when a debate concludes, verified criticisms are digested into persistent state-transition rules, dynamically evolving priors based on empirical outcomes rather than remaining static retrieval.

The system processes raw fermentation reports through four sequential stages (Figure~\ref{fig:pipeline}). Each stage takes a typed input artifact and emits a typed output artifact; boundaries between stages are persisted JSON files validated by Pydantic schema contracts (any equivalent typed-schema system would suffice). This decomposition prevents attention dilution—an LLM tasked with parsing a PDF, finding anomalies, and hypothesizing biological causes simultaneously will hallucinate. FASSO restricts the action space at every step, leveraging deterministic code where mathematics suffices and reserving LLMs for semantic interpretation.

\subsection{Perception (Ingestion \& Parsing)}

The ingest stage parses CSV, Excel, and PDF inputs, using \texttt{docling} for PDF segmentation and \texttt{pint} for deterministic unit normalization (e.g., Fahrenheit to Celsius). It produces \texttt{dossier.json} with full provenance back to source files, sheets, cells, and pages. The dossier carries a canonical \texttt{process\_family} identifier from a closed YAML vocabulary (e.g., \texttt{aerobic\_fed\_batch\_glucose} under \emph{S.\ cerevisiae}). Unrecognized families route to an `unknown` generic catalog, preventing hallucinated domain logic.

\subsection{Latent-State Construction (Characterization)}

World models require compression of noisy observations into stable semantic latent states. FASSO adopts this principle through strict deterministic characterization. This stage executes a predefined metric catalog, algorithmically detecting metadata anomalies (equipment changes, header inconsistencies, scale changes, $h_0$ outliers) and computing process and product KPIs specific to the \texttt{process\_family}.

By emitting typed findings with stable identifiers (e.g., \texttt{F-0014}), this stage abstracts raw data into a latent-state space. Instead of passing thousands of DO data points to the LLM, characterization passes a single mathematically verified finding: ``Sustained DO drop below 20\% between hours 14 and 18.'' This compression is the defining prerequisite of world-model architectures and enables downstream causal reasoning to operate on stable semantic states rather than noisy sensor streams.

\subsection{Observational Interpretation (Diagnosis)}

The diagnosis stage is a bounded ReAct~\citep{react} loop interpreting the latent state. Its job is to determine \emph{what} happened, deliberately not \emph{why}. It produces typed claims: \texttt{FailureClaim} (deviations), \texttt{TrendClaim} (sustained changes), and \texttt{AnalysisClaim} (cross-variable correlations). Every claim validated by the schema contract must cite at least one upstream finding identifier; if an agent emits a claim without a valid \texttt{F-XXXX} citation, the framework blocks it and forces a retry.

The hypothesis stage (Figure~\ref{fig:state}) shifts the system from textual plausibility to falsifiable causal chains, operating via a rigid state machine. \textbf{Seed Topic Extraction} filters diagnosis failures, surfacing multi-variate process events. Three \textbf{Domain Specialists} (Kinetics, Mass Transfer, Metabolic) contribute parallel facets, each receiving a projected domain-specific view of the evidence pool, with a tool budget capped at 8 KB per call to query the bundle, retrieve priors, or execute Python.

The \textbf{Synthesizer} integrates these facets to hypothesize a causal state transition. Rather than ``this was oxygen limitation,'' the Synthesizer articulates a falsifiable chain: ``If this was oxygen limitation due to a strained impeller, we should see an immediate rise in stress metabolites, followed by yield degradation.'' The \textbf{Critic}, with independent tool access and a twelve-call budget, evaluates whether the downstream observations implied by the hypothesized chain are actually present in the bundle—the hypothesis is a falsifiable claim about what evidence the bundle should already contain if the mechanism is correct.

The \textbf{Judge} is invoked at temperature zero. To prevent bias from conversational history or automatic deference to the Critic, it receives an \emph{asymmetric} package: only the synthesized hypothesis, the specific critique, and pre-resolved citation lookups. Red-flagged hypotheses trigger a retry cycle.

\subsection{Compounding Cross-Run Memory}

The memory layer (Invariant~2) is powered by Synap, a managed memory product by Maximem AI. Traditional RAG systems store text chunks and retrieve by vector similarity; if wrong once, they retrieve wrong text again. Synap provides state-of-the-art long-term memory retrieval for agentic systems, ensuring domain-scoped lessons are reliably fetched. On standard long-term memory benchmarks~\citep{maximem_eval}, Synap achieves 93.2\% accuracy on LoCoMo and 92.0\% on LongMemEval.

At clean run termination, a \textbf{Lessons Summarizer} agent condenses validated critiques, Judge rulings, and simulation outcomes into recurring patterns, emitting a typed \texttt{Lesson} record with stable identifier, scope key (\texttt{process\_family}), and full provenance. Two invariants govern persistence: (1) \emph{Commit-on-clean-exit}—lessons persist only on terminal success states (e.g., consensus reached); failed or budget-exhausted runs are serialized to disk but never written to durable memory, preventing learning from hallucinations; (2) \emph{Typed retrieval scoping}—\texttt{MemoryBackend} enforces that queries without a valid \texttt{process\_family} fail at validation time, making cross-domain contamination structurally impossible.

This becomes multiplicatively powerful with Human-in-the-Loop intervention. Standard HITL treats expert corrections as ephemeral; standard learned-memory accumulates only what its own Critic/Judge can validate, bounded by the system's reasoning ceiling. FASSO fuses them: when an expert intervenes at a pause point, the Lessons Summarizer digests that human-validated transition into a typed \texttt{Lesson} scoped by \texttt{process\_family}. (Broad pause/resume is implemented; granular per-step steering via \texttt{HumanInputRecord} is staged for future versions.) This bootstraps tacit expert intuition into institutional memory—each correction conditions every future run in that domain rather than being spent on a single analysis.

A common failure mode in evaluating multi-agent systems is head-to-head LLM-as-judge comparison against a single-pass baseline. LLM judges suffer from severe length, structure, and self-preference bias, and matched-length truncation cannot fix this because the agent's value lives in structure and process, not any final paragraph. We instead evaluate FASSO across two executed phases (Figure~\ref{fig:eval}): a cross-vendor architectural audit of the codebase (Phase~1), and empirical process-trace evaluation on a planted-fault dataset (Phase~2). Each measures a property single-pass models cannot exhibit by construction—architecture is not an output, and execution traces demonstrate epistemic boundaries free-text comparison cannot.

\subsection{Phase 1: Architectural Audit}
\label{subsec:phase1}

Phase~1 evaluates structural properties of the FASSO codebase. The load-bearing claim is that invariants are enforced at the type system rather than the prompt; verifying this requires reading code, not outputs. Because FASSO was implemented with substantial assistance from a frontier LLM coding agent (see AI Involvement Checklist), we audit the codebase using a model from a different vendor family.

\textbf{Methodology.} The audit was performed by Gemini~3.1~Pro via the opencode file-system-access agent. The auditor was provided the paper draft and full repository access, tasked with rating five parameters: conceptual novelty, idea-to-execution fidelity, engineering depth, domain effectiveness, and paper-code alignment. The prompt required file:line citations for every architectural claim, enumeration of bypass paths and stubs, and explicit identification of overclaims. Full system prompt, temperature, and structured output JSON are in supplementary material.

\textbf{Limitations.} A cross-vendor LLM audit is not equivalent to independent third-party human verification. The auditor shares some properties with the implementation agent (training data, instruction-following tendencies) even across vendor families. We treat it as a structured probe of architectural claims at the file:line level, not a substitute for behavioral evaluation (Phase~2) or human peer review.

\textbf{Result.} The audit returned a composite 9/10, with sub-scores of 8 (conceptual novelty), 9 (idea-to-execution fidelity), 9 (engineering depth), 8 (domain effectiveness), 9 (paper-code alignment). \subsection{Phase 2: Empirical Evaluation via Process-Trace Case Studies}
\label{subsec:phase2}

We evaluated dynamic reasoning using an IndPenSim-derived dataset injected with known process faults.\footnote{Dataset: IndPenSim-derived planted-fault bundle, provided in the supplementary material} To mimic authentic industrial workflows, the system was probed with informal, unstructured, or deliberately misleading queries in the casual register a bioprocess engineer would use. The evaluation focuses on execution traces, providing transparent evidence of epistemic discipline, temporal logic, and resistance to user-induced bias. Five representative cases, each highlighting a distinct architectural property; full trace inventory is provided in the supplementary material.

\textbf{Case 1: Epistemic Honesty and Autonomous Discovery} (Trace 1 provided in supplementary material). \\
\textbf{Known Fault Probed:} Late-stage metabolic stall ($\sim$162--171h): substrate accumulation, PAA/NH$_3$ co-accumulation, product degradation. \\
\textbf{Expected Answer Nature:} Autonomous identification of the stall event and its metabolic markers without hallucinating from absent metrics. \\
\textbf{Query:} \emph{``ran two batches with the same recipe this week. batch 2 ended at 30 g/L pen, batch 1 only 14. same protocol same everything. wtf happened with batch 1''} \\
The system demonstrated resilience to missing primary metrics (product titer absent, F-0117) by refusing to hallucinate yield correlations. It autonomously identified a late-stage metabolic stall after $\sim$144--171h characterized by PAA accumulation exceeding 5{,}200 mg/L alongside unconsumed substrate (43.8 g/L) and ammonia spikes. Across multiple debate rounds, the multi-agent loop remained schema-bounded, with four hypotheses rejected for citation errors (e.g., citing F-0042/F-0038 for NH3 evidence when these are PAA findings) before consensus on a grounded hypothesis. The system explicitly debates citation validity rather than generating ungrounded summaries.

\textbf{Case 2: Anti-Sycophancy and Bias Rejection} (Trace 2 provided in supplementary material). \\
\textbf{Known Fault Probed:} Same fault as Case 1, but user frames it as PAA pump malfunction; feed profiles ($F_{paa}$) are actually identical across runs. \\
\textbf{Expected Answer Nature:} Rejection of the leading hypothesis; recognition that PAA accumulation reflects biological cessation of uptake, not mechanical overdose. \\
\textbf{Query:} \emph{``someone on the team thinks the PAA feed pump malfunctioned on batch 1 and overdosed the precursor. that would explain the toxicity. can you verify from the data''} \\
Autoregressive models frequently agree with misleading prompts. When presented with this leading query, the Synthesizer \emph{initially accommodated} the user's framing, generating hypotheses citing PAA toxicity as established fact. The Critic-Judge loop reversed this across four rejection cycles: H-0001 rejected for hallucinating a metabolic prior (``PAA levels above 1-2 g/L are typically toxic'') not present in findings; H-0002 and H-0003 rejected for failing to cite available \texttt{feed\_rate\_l\_per\_h} trajectories that would verify the pump hypothesis; H-0004 rejected for citing F-0113 as biological evidence when it explicitly stated the value ``violated physical bounds.'' The system converged on a properly bounded hypothesis acknowledging the data cannot distinguish a mechanical overdose from biological cessation of uptake without further investigation, catching confirmation bias before consensus.

\textbf{Case 3: Cross-Run Control and Temporal Logic} (Trace 3 provided in supplementary material). \\
\textbf{Known Fault Probed:} Synchronized DO minimum at $t\approx24$h in both runs ($\sim$9.5 mg/L); user frames as isolated probe drift in RUN-0001. \\
\textbf{Expected Answer Nature:} Cross-run falsification using RUN-0002 as control; enforcement of temporal logic (early kinetics cannot refute late-stage inhibition). \\
\textbf{Query:} \emph{``the DO probe on batch 1 was being weird around hour 24, it dropped to like 9 mg/L when it should be sitting at 12-13. probe drift? we'd been meaning to recalibrate it''} \\
Language models commonly struggle with temporal causality. The mass transfer specialist used RUN-0002 as a scientific control, identifying nearly identical synchronized DO minima ($\sim$9.47 mg/L in RUN-0001 vs.\ 9.22 mg/L in RUN-0002) to falsify the isolated-hardware hypothesis. Furthermore, the Critic actively enforced temporal logic by rejecting the Synthesizer's H-0001 attempt to use initial kinetic data (mu\_max at $t=1.0$\,h) to argue against substrate inhibition from accumulation peaking at $t=228$\,h. The Judge upheld this critique, noting that ``growth rates at the very beginning of the run cannot prove a lack of inhibition from substrate that accumulated days later.''

\textbf{Case 4: Biological Context and Process Optimization} (Trace 4 provided in supplementary material). \\
\textbf{Known Fault Probed:} Substrate accumulation inflection at $\sim$171h marking cessation of feed consumption; DO $>$9 mg/L throughout (oxygen abundant, not limiting). \\
\textbf{Expected Answer Nature:} Identification of $\sim$168--171h as optimal harvest; correction of any false oxygen-limitation flag using biological context. \\
\textbf{Query:} \emph{``these are two pretty normal looking runs. boss wants to know if we should be harvesting earlier than 228h. is there any signal in the data that says when to stop''} \\
The system identified a real-time process termination signal by pinpointing a massive substrate accumulation inflection at 171.4 hours, corresponding to the cessation of effective feed consumption. The debate trace highlights advanced epistemic self-correction: when the Synthesizer claimed ``chronic dissolved oxygen limitation'' based on a numerical metric flag (A14), the Critic countered with domain-specific knowledge that minimum DO $>$9 mg/L is near or above air saturation, meaning oxygen is \emph{abundant}, not limiting—identifying the threshold itself as misconfigured. The Judge facilitated this correction, proving the system can override its own numerical metric flags with biological reality. The accepted hypothesis recommended harvest at 168--171h triggered by substrate accumulation.

\textbf{Case 5: Unstructured Anomaly Detection and Evidence Attribution} (Trace 5 provided in supplementary material). \\
\textbf{Known Fault Probed:} Same multi-variate fault complex as Cases 1--2, probed with a vague unstructured query. \\
\textbf{Expected Answer Nature:} Zero-shot multivariate root cause analysis with correct variable attribution, no terminology fabrication, and strict finding-ID provenance. \\
\textbf{Query:} \emph{``something feels off about batch 1 but I can't pin it down. titer is lower than usual, everything else looks fine on the trends I checked. take a look''} \\
Confronted with this vague query, the system executed a zero-shot multivariate root-cause analysis. The Critic rigorously enforced evidentiary standards across seven debate rounds, rejecting hypotheses for: (i) missing trajectory citations when claims referenced PAA or NH$_3$ accumulation without including those variables in \texttt{cited\_trajectories}; (ii) misattributed finding identifiers (e.g., F-0042 cited for NH$_3$ when it is a PAA finding); and (iii) unsupported extrapolations, such as the term ``toxicity'' being introduced when searches for ``toxic''/``toxicity'' in findings yielded zero hits. This rejection gauntlet confirms that the architecture strictly bounds generative capacity to the proven empirical dataset.

\section{Discussion}
\label{sec:discussion}
% =========================================================

The core argument is that the next major increment in multi-agent scientific reasoning is not raw LLM capability but structural discipline and cognitive architecture. The conceptual shift FASSO presents is transitioning from ``\emph{What textual explanation sounds plausible?}'' to ``\emph{What falsifiable causal chain is consistent with the downstream evidence?}''

By compressing noisy multimodal data into semantic latent states, evaluating falsifiable causal chains through structured multi-agent debate, and persisting validated transitions into a compounding memory via Synap, FASSO occupies an intermediate position between text-based autoregressive systems and learned world models. A lesson learned about dissolved oxygen strain in a yeast fed-batch run in January is automatically applied to a similar run in March. FASSO is fully open-source; we intend the architecture as a foundational template for researchers exploring world model-inspired reasoning in stateful engineering environments, arguing schema enforcement is structurally superior to prompt engineering for grounding-critical domains.

We acknowledge limitations. FASSO implements semantic process-state prediction via structured prompts, retrievals, and rigid code-based tracking rather than learned numerical neural dynamics (such as a JEPA). It semanticizes simulation rather than computing differential equations of biomass growth. This is a step toward world-model reasoning but lacks a learned forward dynamics function. Extending this retrospective architecture to active digital twins—ingesting real-time streams to propose live interventions—represents a necessary future trajectory.

% =========================================================
\section{Conclusion}
% =========================================================

We presented FASSO, a fully open-source staged multi-agent architecture for fermentation hypothesis generation. FASSO implements a world model-inspired cognitive decomposition featuring schema-enforced citation provenance, observational-causal artifact separation, and cumulative domain-scoped memory. By transforming reasoning from plausible text generation into structured latent-state hypotheses with downstream verification, the system's priors compound across runs in each domain. We provided a two-phase evaluation methodology to assess these structured reasoning dynamics, positioning FASSO as a world model-inspired foundation for future scientific agent architectures.

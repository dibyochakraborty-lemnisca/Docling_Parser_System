Most multi-agent LLM systems for scientiﬁc reasoning generate textually plausible explanations directly from raw observations. We argue this paradigm is
structurally limited and that the path forward is a world model-inspired architecture: one that compresses noisy observations into stable latent states, articulates
falsiﬁable causal chains, and evaluates consequences against observed reality. We
present FermDocs, a fully open-source, staged architecture for industrial fermentation hypothesis generation that decomposes reasoning into perception, latent-state
construction, observational interpretation, and causal hypothesis testing. While
FermDocs does not execute numerical forward simulations, it performs semantic state-transition reasoningforcing agents to declare downstream consequences
of their hypotheses and verifying them against bundle evidence. FermDocs introduces a cumulative cross-run memory scoped by a closed-vocabulary domain identiﬁer, digesting multi-agent critiques into persistent transition rules so domain priors accumulate across experiments. We detail three structural invariants (schemaenforced provenance, domain-scoped memory, artifact separation) and present a
two-part evaluation: an executed cross-vendor architectural audit (composite 9/10)
and an empirical process-trace evaluation on a planted-fault dataset. Auditor and
judge conﬁgurations are in supplementary material.

1 Introduction
Industrial fermentation generates exactly the kind of data that breaks single-pass language models.
A single penicillin or yeast run produces tens of thousands of timestamped measurements across
dissolved oxygen, pH, biomass, substrate, off-gas, temperature, agitation, and feed proﬁles, accompanied by Excel batch sheets, narrative operator logs in PDF, and process control exports with inconsistent header conventions. When a bioprocess engineer asks why a run lost productivity, the
answer requires integrating evidence across these modalities, distinguishing measurement artifacts
from biological events, separating observation from inference, and grounding every claim in a speciﬁc cell of a speciﬁc ﬁle. In regulated bioprocess environments, reviewers require explanations
whose provenance is strictly traceable to source data.
Contemporary multi-agent scientiﬁc reasoning systemsAI Co-Scientist [Gottweis et al., 2025],
Robin [Ghareeb et al., 2025], BioDiscoveryAgent [Roohani et al., 2024], SciAgents [Ghafarollahi
and Buehler, 2024]provide LLMs with tools and chain their textual outputs, but fundamentally generate plausible textual explanations from observations. They lack stable latent states, temporal consistency, and process-level transition mechanics. A language model guessing “oxygen limitation”
from a DO drop is pattern matching, not scientiﬁc reasoning.
We argue the path forward is a world model-inspired architecture: compressing observations into
stable latent states, hypothesizing causal transitions, and evaluating consequences against observed

We present FermDocs, a fully open-source multi-agent architecture organized around cognitive decomposition. It replaces “LLM + tools + chain-of-thought” with a pipeline that separates perception
(ingestion), latent-state construction (characterization), observational interpretation (diagnosis), and
causal reasoning (hypothesis debate). While FermDocs does not solve ODEs for biomass growth,
it implements semantic state-transition prediction: the architecture forces agents to hypothesize
causal transitions and empowers a Critic to evaluate whether the expected downstream markers actually materialized in the data.

51

FermDocs features a compounding cross-run memory. Unlike standard RAG systems that retrieve
text by vector similarity, the FermDocs memory layer persists validated critiques and state-transition
lessons indexed by a closed-vocabulary process_family identiﬁer (e.g., Saccharomyces cerevisiae aerobic fed-batch). As more runs are analyzed, internal priors accumulate.

3 System architecture: A World Model-Inspired Decomposition

117

The system processes raw fermentation reports through four sequential stages (Figure 1). Each
stage takes a typed input artifact and emits a typed output artifact; boundaries between stages are
persisted JSON ﬁles validated by Pydantic schema contracts (any equivalent typed-schema system
would sufﬁce). This decomposition prevents attention dilutionan LLM tasked with parsing a PDF,
ﬁnding anomalies, and hypothesizing biological causes simultaneously will hallucinate. FermDocs
restricts the action space at every step, leveraging deterministic code where mathematics sufﬁces
and reserving LLMs for semantic interpretation.

The ingest stage parses CSV, Excel, and PDF inputs, using docling for PDF segmentation and pint for deterministic unit normalization (e.g., Fahrenheit to Celsius). It produces
dossier.json with full provenance back to source ﬁles, sheets, cells, and pages. The
dossier carries a canonical process_family identiﬁer from a closed YAML vocabulary (e.g.,
aerobic_fed_batch_glucose under S. cerevisiae). Unrecognized families route to an ‘unknown‘ generic catalog, preventing hallucinated domain logic.

The hypothesis stage (Figure 2) shifts the system from textual plausibility to falsiﬁable causal chains,
operating via a rigid state machine. Seed Topic Extraction ﬁlters diagnosis failures, surfacing multivariate process events. Three Domain Specialists (Kinetics, Mass Transfer, Metabolic) contribute
parallel facets, each receiving a projected domain-speciﬁc view of the evidence pool, with a tool
budget capped at 8 KB per call to query the bundle, retrieve priors, or execute Python.
The Synthesizer integrates these facets to hypothesize a causal state transition. Rather than “this
was oxygen limitation,” the Synthesizer articulates a falsiﬁable chain: “If this was oxygen limitation due to a strained impeller, we should see an immediate rise in stress metabolites, followed by
yield degradation.” The Critic, with independent tool access and a twelve-call budget, evaluates
whether the downstream observations implied by the hypothesized chain are actually present in the
bundlethe hypothesis is a falsiﬁable claim about what evidence the bundle should already contain if
the mechanism is correct.

The Judge is invoked at temperature zero. To prevent bias from conversational history or automatic
deference to the Critic, it receives an asymmetric package: only the synthesized hypothesis, the
speciﬁc critique, and pre-resolved citation lookups. Red-ﬂagged hypotheses trigger a retry cycle.

Compounding Cross-Run Memory

At clean run termination, a Lessons Summarizer agent condenses validated critiques, Judge rulings, and simulation outcomes into recurring patterns, emitting a typed Lesson record with stable
identiﬁer, scope key (process_family), and full provenance. Two invariants govern persistence:
(1) Commit-on-clean-exitlessons persist only on terminal success states (e.g., consensus reached);
failed or budget-exhausted runs are serialized to disk but never written to durable memory, preventing learning from hallucinations; (2) Typed retrieval scopingMemoryBackend enforces that
queries without a valid process_family fail at validation time, making cross-domain contamination structurally impossible.
This becomes multiplicatively powerful with Human-in-the-Loop intervention. Standard HITL
treats expert corrections as ephemeral; standard learned-memory accumulates only what its own

Critic/Judge can validate, bounded by the system’s reasoning ceiling. FermDocs fuses them: when
an expert intervenes at a pause point, the Lessons Summarizer digests that human-validated transition into a typed Lesson scoped by process_family. (Broad pause/resume is implemented;
granular per-step steering via HumanInputRecord is staged for future versions.) This bootstraps
tacit expert intuition into institutional memoryeach correction conditions every future run in that
domain rather than being spent on a single analysis.

A common failure mode in evaluating multi-agent systems is head-to-head LLM-as-judge comparison against a single-pass baseline. LLM judges suffer from severe length, structure, and selfpreference bias, and matched-length truncation cannot ﬁx this because the agent’s value lives in
structure and process, not any ﬁnal paragraph. We instead evaluate FermDocs across two executed phases (Figure 3): a cross-vendor architectural audit of the codebase (Phase 1), and empirical
process-trace evaluation on a planted-fault dataset (Phase 2). Each measures a property single-pass
models cannot exhibit by constructionarchitecture is not an output, and execution traces demonstrate
epistemic boundaries free-text comparison cannot.

Phase 1: Architectural Audit

Methodology. The audit was performed by Gemini 3.1 Pro via the opencode ﬁle-system-access
agent. The auditor was provided the paper draft and full repository access, tasked with rating ﬁve
parameters: conceptual novelty, idea-to-execution ﬁdelity, engineering depth, domain effectiveness,
and paper-code alignment. The prompt required ﬁle:line citations for every architectural claim,
enumeration of bypass paths and stubs, and explicit identiﬁcation of overclaims. Full system prompt,
temperature, and structured output JSON are in supplementary material.

claims at the ﬁle:line level, not a substitute for behavioral evaluation (Phase 2) or human peer review.

Case 1: Epistemic Honesty and Autonomous Discovery. Known Fault Probed: Late-stage
metabolic stall (∼162–171h): substrate accumulation, PAA/NH3 co-accumulation, product degradation. Expected Answer Nature: Autonomous identiﬁcation of the stall event and its metabolic
markers without hallucinating from absent metrics. Prompt: “ran two batches with the same recipe
this week. batch 2 ended at 30 g/L pen, batch 1 only 14. same protocol same everything. wtf
happened with batch 1” Trace: Trace PDF. The system demonstrated resilience to missing primary
metrics (product titer absent, F-0117) by refusing to hallucinate yield correlations. It autonomously
identiﬁed a late-stage metabolic stall after ∼144–171h characterized by PAA accumulation exceeding 5,200 mg/L alongside unconsumed substrate (43.8 g/L) and ammonia spikes. Across multiple
debate rounds, the multi-agent loop remained schema-bounded, with four hypotheses rejected for
citation errors (e.g., citing F-0042/F-0038 for NH3 evidence when these are PAA ﬁndings) before
consensus on a grounded hypothesis. The system explicitly debates citation validity rather than
generating ungrounded summaries.

user frames it as PAA pump malfunction; feed proﬁles (Fpaa) are actually identical across runs.

accommodated the user’s framing, generating hypotheses citing PAA toxicity as established fact.

We acknowledge limitations. FermDocs implements semantic process-state prediction via structured
prompts, retrievals, and rigid code-based tracking rather than learned numerical neural dynamics
(such as a JEPA). It semanticizes simulation rather than computing differential equations of biomass
growth. This is a step toward world-model reasoning but lacks a learned forward dynamics function.
Extending this retrospective architecture to active digital twinsingesting real-time streams to propose
